# 貸切バス料金シミュレータ

出発地・到着地を入力して総運行距離・総運行時間を取得し、台数を入力すると、一般貸切旅客自動車運送事業の運賃・料金（2025年11月1日改定の下限額）に基づく概算料金を試算する単一HTMLページです。

入力項目：①台数 ②総運行距離 ③総運行時間（②③は出発地・到着地の地名から往復の経路検索で自動入力、手入力で上書き可。経路は地図に表示）

- `index.html` をそのままウェブサーバーに置けば動作します（GitHub Pages で公開可）。
- 距離・所要時間は OpenStreetMap の Nominatim / OSRM 公開サーバーから取得します。接続できない場合は直線距離からの概算に切り替わります。
- 表示額は法令上の下限額に基づく目安です。有料道路料金・駐車料等の実費は含みません。

## 計算の前提

- 時間制運賃＋キロ制運賃の併用制。往復の拘束時間に出庫前・帰庫後の点呼点検各1時間を加算（日帰り前提）。
- 走行時間は3時間未満を3時間として計算。距離は10km単位切上げ、時間は30分未満切捨て・30分以上切上げ。
- 運転9時間超または500km超で交替運転者配置料金を自動加算。消費税10%。
- オプション：バスガイド（1台につき1名、1人1日20,000円税抜）。

運賃率を変更する場合は `index.html` 内スクリプト冒頭の `RATES` を編集してください。
